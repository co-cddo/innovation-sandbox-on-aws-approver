## Project Context

### What We're Building

A **score-based lease approval system** that intercepts Innovation Sandbox lease requests and makes intelligent approval decisions:

- **Auto-approve** low-risk requests (score < 20)
- **Delay** requests outside UK business hours
- **Queue** requests when no accounts available
- **Escalate** high-risk requests to manual approval
- **Notify** via Slack for non-immediate approvals
