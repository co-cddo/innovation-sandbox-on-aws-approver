## Challenges Encountered

### 1. CDK Rule Weights Sync
**Issue:** CDK `environments.ts` had old scoring weights (`endOfWindow: -2`, `outsideTargetAudience: 10`) while `src/scoring/types.ts` had updated values
**Impact:** Deployed Lambda had incorrect scoring behavior
**Resolution:** Updated CDK config to match: `endOfWindow: 2`, `outsideTargetAudience: 50`
**Lesson:** When modifying scoring rules in code, also update CDK environment config

### 2. Log Group Retention Discrepancy
**Issue:** CloudWatch log group existed with 365-day retention instead of 7-year
**Impact:** GDPR compliance requirement not met
**Resolution:** Manually updated retention via AWS CLI: `put-retention-policy --retention-in-days 2557`
**Lesson:** CDK won't update existing log groups - manual intervention needed for existing resources

### 3. Orphaned Code from Course Corrections
**Issue:** Multiple references to removed `isLocalGovernment`/`isOutsideTargetAudience` AI fields remained in mocks and comments
**Impact:** Confusing code, potential type errors
**Resolution:** Three code review passes to catch all orphans (9 mock occurrences, multiple comments)
**Lesson:** Major refactors require thorough grep-based cleanup

### 4. Terminology Inconsistency
**Issue:** `end_of_window` rule changed from bonus (-2) to penalty (+2) but comments and test names still said "bonus"
**Impact:** Documentation/code mismatch
**Resolution:** Updated all references to use "penalty" terminology
**Lesson:** When changing rule semantics, search for all related documentation

## Key Insights

1. **Flat JSON for Slack Workflows** - Slack Workflow Webhooks require flat JSON (no nested objects). The Workflow Builder handles message formatting, making our payload simpler.

2. **Graceful Degradation Pattern** - All external integrations (Slack, Secrets Manager, CloudWatch) fail gracefully without affecting core approval flow. The pattern is well-established.

3. **E2E Milestones Are Valuable** - Interactive E2E testing caught the CDK config drift that unit tests couldn't detect.

4. **Code Reviews Catch Orphans** - Multiple adversarial code review passes are essential after major refactors or course corrections.

5. **CDK and Code Must Stay Sync** - Environment variables in CDK are a second source of truth that can drift from application code.
