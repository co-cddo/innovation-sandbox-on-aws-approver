## Challenges & Learnings

### Critical Discovery: ISB Integration Mismatch

**Problem:** We assumed ISB processes `LeaseApproved` events from EventBridge. It doesn't.

**Reality:** ISB expects direct Lambda invocation via `POST /leases/{leaseId}/review`. It *emits* LeaseApproved events *after* processing approvals.

**Impact:**
- `emitLeaseApproved` method became orphan code
- Had to create `isb-lambda.ts` service for direct invocation
- Story 2.5 required significant pivot

**Root Cause:**
- Insufficient analysis of ISB codebase before building integration layer
- Documentation (`isb-integration-reference.md`) contained incorrect assumptions

### Other Challenges

1. **CDK asset caching** - Deployed stale code because bundle wasn't rebuilt
2. **100% branch coverage threshold** - Too aggressive, reduced to 90%
3. **Handler idempotency wrapping** - Deferred due to complexity
